## 📦 Installation

### Method 1: Upload via WordPress Admin

1. Download the theme ZIP file from GitHub
2. Go to **WordPress Admin → Appearance → Themes → Add New → Upload Theme**
3. Choose the ZIP file and click **Install Now**
4. Click **Activate** after installation

### Method 2: Manual Installation

1. Download the theme ZIP file
2. Extract to `wp-content/themes/` directory
3. Go to **WordPress Admin → Appearance → Themes**
4. Find "Lux Modern" and click **Activate**

### Method 3: Clone from GitHub

```bash
cd wp-content/themes/
git clone https://github.com/jawadjk020/lux-modern-wp-theme.git
```

## ⚙️ Setup

1. **Set Homepage**: Go to **Settings → Reading** and set a static page as homepage
2. **Configure Menus**: Go to **Appearance → Menus** and create a Primary Menu
3. **Add Logo**: Go to **Appearance → Customize → Site Identity** and upload your logo
4. **Customize Colors**: Go to **Appearance → Customize → Lux Modern Options**
